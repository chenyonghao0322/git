# 更新日志

## v0.5（2026-07-23）

### 新增：Halcon 形状模板匹配

- 菜单「2D算子 → halcon匹配」，与「2D模板匹配」并存
- 封装 `HalconShapeMatch`：`CreateScaledShapeModel` / `FindScaledShapeModel`、`.shm` 保存/加载
- CMake 可选链接 Halcon 20.11，Release 自动复制运行时 DLL
- 全屏嵌入主窗口（与算法编辑器同风格），非独立浮动窗
- 支持整图创建或旋转 ROI 框选创建模板
- 模板轮廓预览、匹配结果轮廓叠加、得分/缩放标注

### 新增：2D 模板匹配（OpenCV）

- 菜单「2D算子 → 2D模板匹配」
- 封装 `ShapeTemplateMatch`：创建/查找/保存/加载形状模板

### 新增：点云数据库树（DbTree）

- 侧栏点云图层树形管理（`DbTreePanel`）
- 多图层显示/隐藏、选中切换

### Halcon 匹配修复与优化（2026-07-23）

| 问题 | 处理 |
|------|------|
| 框选 ROI 后轮廓仍是整图 | `CropRectangle2` 物理裁剪 ROI |
| 匹配轮廓偏移（缩放≠1） | 按 Halcon 官方 `VectorAngleToRigid` + `HomMat2dScale(Row,Col)` 变换 |
| ROI 框选后左右被截断 | 修正 `Length1/Length2` 与宽高的对应关系 |
| 整图出现最外圈矩形轮廓 | 复制扩边（BORDER_REPLICATE）+ domain 内缩 |
| 最小得分 0.75 漏检、0.4 却显示 0.84 | 搜索阶段放宽阈值，结果按用户最小得分二次过滤 |
| 大目标内误检小缩放 | 嵌套误检过滤；默认最小得分 0.75 |

### 其他

- `Application`：3D 多图层、ICP、段差、2D 工具等配套扩展
- `OpenCv2D`：模板匹配与若干 2D 算子增强
- `FileDialog`：支持 `.shm` / 模板文件对话框

## v0.4（2026-07-22）

### 新增：2D 图像算子（OpenCv2D）

在菜单「2D算子」中新增 18 个测量算子，支持深度图 / 亮度图叠加显示与交互：

| 算子 | 说明 |
|------|------|
| 点点距离 | 两点间欧氏距离 |
| 线线夹角 | 两条拟合线段的夹角 |
| 圆间隙 | 两圆表面间隙 |
| 点线距离 | 点到线段垂直距离 |
| 点卡尺 | 单点边缘提取 |
| 圆卡尺 | 圆形 ROI 边缘拟合 |
| 弧长 | 圆弧长度 |
| 三点圆 | 三点确定圆 |
| 平行线距离 | 两平行线间距 |
| 矩形卡尺 | 矩形 ROI 四边提线 |
| 椭圆拟合 | 椭圆卡尺拟合 |
| 轮廓宽度 | 剖面宽度测量 |
| 点投影 | 点到线段垂足投影 |
| 同心度 | 两圆同心偏差 |
| 圆度 | 圆卡尺圆度评估 |
| 区域连通 | Blob 区域分析 |
| 深度高度差 | 深度图两点高度差 |
| 深度剖面 | 深度图沿线剖面曲线 |

原有算子保留：线卡尺、弧卡尺、线距、弧距、圆拟合。

### 新增：2D 图像工作流

- 支持单独打开深度图 / 亮度图（PNG / TIFF / BMP / JPEG），不转点云
- 2D 模式：隐藏 3D 视区，专注图像测量
- 深度 / 亮度图联动十字线
- 截面 2D 轮廓窗口支持标题栏关闭与重新打开

### 修复：2D 测量清理

- 「清除全部线段」「清除全部圆弧」现会同步清除圆拟合、椭圆拟合及相关测量状态
- 「清空显示」现会一并清除 2D 叠加（线、点、圆、卡尺等）
- 新增菜单项「清除全部 2D 测量」一键清空

### 优化：界面（预览版）

- 统一 `UiPalette` 色板，深蓝灰工业风主题
- 工具栏胶囊状态标签、底部强调线
- 侧栏点云信息卡片化、分区标题色条
- 输出台日志区边框与条数显示
- 菜单栏左侧品牌标识

### 其他

- 新增 `OpenCv2D.cpp / OpenCv2D.h` 2D 算法模块
- 算法编辑器、测量工具等配套更新
