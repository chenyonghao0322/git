# 更新日志

## v0.4（2026-07-22）

### 新增：2D 图像算子（OpenCv2D）

在菜单「2D算子」中新增 18 个测量算子，支持深度图 / 亮度图叠加显示与交互：

| 算子 | 说明 |
|------|------|
| 点点距离 | 两点间欧氏距离 |
| 线线夹角 | 两条拟合线段的夹角 |
| 圆间隙 | 两圆表面间隙 |
| 点线距离 | 点到线段垂直距离 |
| 点卡尺 | 单点边缘提取 |
| 圆卡尺 | 圆形 ROI 边缘拟合 |
| 弧长 | 圆弧长度 |
| 三点圆 | 三点确定圆 |
| 平行线距离 | 两平行线间距 |
| 矩形卡尺 | 矩形 ROI 四边提线 |
| 椭圆拟合 | 椭圆卡尺拟合 |
| 轮廓宽度 | 剖面宽度测量 |
| 点投影 | 点到线段垂足投影 |
| 同心度 | 两圆同心偏差 |
| 圆度 | 圆卡尺圆度评估 |
| 区域连通 | Blob 区域分析 |
| 深度高度差 | 深度图两点高度差 |
| 深度剖面 | 深度图沿线剖面曲线 |

原有算子保留：线卡尺、弧卡尺、线距、弧距、圆拟合。

### 新增：2D 图像工作流

- 支持单独打开深度图 / 亮度图（PNG / TIFF / BMP / JPEG），不转点云
- 2D 模式：隐藏 3D 视区，专注图像测量
- 深度 / 亮度图联动十字线
- 截面 2D 轮廓窗口支持标题栏关闭与重新打开

### 修复：2D 测量清理

- 「清除全部线段」「清除全部圆弧」现会同步清除圆拟合、椭圆拟合及相关测量状态
- 「清空显示」现会一并清除 2D 叠加（线、点、圆、卡尺等）
- 新增菜单项「清除全部 2D 测量」一键清空

### 优化：界面（预览版）

- 统一 `UiPalette` 色板，深蓝灰工业风主题
- 工具栏胶囊状态标签、底部强调线
- 侧栏点云信息卡片化、分区标题色条
- 输出台日志区边框与条数显示
- 菜单栏左侧品牌标识

### 其他

- 新增 `OpenCv2D.cpp / OpenCv2D.h` 2D 算法模块
- 算法编辑器、测量工具等配套更新
